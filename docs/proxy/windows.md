# FLClash
使用步骤：
网站-仪表盘-一键订阅-复制订阅地址
FLClash - 配置 - 右下角“+”号 - URL - 粘贴 - 提交
代理 - 选择节点 - 右下角测速 - 仪表盘 - 启动

# Clash Verge
使用步骤：
网站-仪表盘-一键订阅-复制订阅地址
Clash Verge - 订阅 - 新建 - 订阅链接（粘贴） - 更新间隔（1440 分钟） - 保存
代理 - 选择节点 - 系统代理（电脑右下角找到 Clash Verge 图标，右键选择“系统代理”）
